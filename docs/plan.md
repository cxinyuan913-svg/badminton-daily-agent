# 開發計畫

以每週 10–12 小時估算，共 8 週。每階段有關卡，沒過不進下一階段。
完整的視覺版報告在 claude.ai artifact「羽球日報 Agent 開發計畫」。

## 架構

```
收集（每日 06:00）          儲存                    判斷與生成                 產出
賽果爬蟲  ──────────▶  SQLite / PostgreSQL ──┐
                                               ├──▶ Agent ──▶ Discord 每日摘要
新聞收集  ──────────▶  向量庫（新聞切塊）─────┘     ① 挑今日題材      1 分鐘影片草稿
                                                     ② 查歷史（SQL/RAG） 選手時間軸頁
                                                     ③ 寫草稿 → 事實檢查
```

精確問題（對戰紀錄、勝負數）走 SQL；模糊問題（爆冷、狀態、黑馬）走 RAG + LLM；混合題兩條都走。

- **關卡**：連續兩週每天產出，事實錯誤率 0，實際拍攝至少 3 支
