# 世界排名重建：驗證報告

交接單 002 第 5 步。2026-09-30 產出，Claude Code。

## 為什麼要重建

判斷「爆冷」需要比賽當週的世界排名。但 BWF 排名 API 只保留最近約 60 週（2026-09 實測，最早到 2025-08-12），更早的比賽查不到當時的排名。所以我們用自己回補的十年比賽資料，照 BWF 規章重算每週排名。

**驗證方法**：拿 API 還留著的 60 週官方排名（`ranking_snapshot`，每項目約前 500 名），比對同一週的重建結果（`ranking_estimate`，只存前 100 名）。

## 結論（先講重點）

- **前 10 名幾乎完全重現**：5 個項目的官方前 10 名，95.5–99.2% 的估算誤差在 2 名以內
- **前 50 名誤差 ≤ 2 的比例是 70.9–84.7%**，未達暫定目標 90%
- 差距集中在 **50 名以後**。主因是追蹤範圍不含 **Future Series**：中段、後段選手的積分有一部分來自它
- 驗證過程找到 **7 個系統性錯誤**並修正，前 50 名的準確率因此提高 5–9 個百分點

## 找到並修正的錯誤

每一項都附了測試（`tests/test_results.py`、`tests/test_ranking_estimate.py`）。

1. **成績計入的日期**：原本用「選手在該站最後一場的日期」，所以早早出局的人會提早一週被算進排名。官方是整站結束後才計入。例：石宇奇 9/26 在亞運 16 強出局，但亞運 9/29 才結束，不在 9/29 的官方排名裡。
2. **年終總決賽小組賽沒計分**：小組賽的輪次叫 R1–R3，程式不認得，所以小組就出局的選手拿 0 分。改為依規章 4.2.6 計算：小組第 3 名比照 5/8、第 4 名比照 9/16。奧運的「Group A」也用同樣規則。
3. **團體賽沒計分**：交接單原本寫「團體賽不計入個人排名」，但規章 7.1 寫明湯尤盃、蘇迪曼盃、洲際團體賽都會計入。計分方式是「平均分 + 贏球時對手總積分 / 100」。規章沒寫清楚一站要怎麼彙總，**用官方排名反推，結果是取該站單場最高分**：5 位選手的差距都吻合，例如石宇奇差 9,135 分，公式推算差 9,100 分。52 週內只取最好的一次團體賽。
4. **團體賽的平均分查不到**：2025 年 4–5 月的蘇迪曼盃早於官方快照，原本所有人都被當成「沒有排名」。改為先重建 2024-06 到 2025-08 的歷史排名，再用它算平均分。這一步讓混雙提升了 3.7 個百分點。
5. **API 缺決賽**：例如 2026 亞錦賽的混雙決賽不在 day-matches 裡。原本四強勝方完全沒有成績；改為整站結束時至少給亞軍（保守估計）。
6. **舊年度的輪次寫法**：`Semi-finals`、`Quarterfinals`、`Round of 16`、奧運銅牌戰 `3/4`，還有輪次為 NULL 的場次（原本會讓程式當掉）。
7. **Lucky loser 奪冠**：在頒獎台抽查時發現。2024 荷蘭國際賽混雙的冠軍，資格賽最後一輪不戰而敗，遞補進正賽後一路奪冠，原本卻只拿到資格賽的積分。

## 還沒解決的差異

| 原因 | 影響 | 證據 |
|---|---|---|
| **Future Series 不在追蹤範圍**（已決議不收） | 主要影響 50–100 名 | 最新一週男單前 50 名裡，31 人是官方比我們多 1 站。例：Kevin CORDON 官方 11 站、我們 7 站 |
| 洲際團體錦標賽（泛美、歐洲、亞洲團體賽）不在年度賽程的追蹤分類 | 中後段 | 差最多的 15 個組合多來自美洲、歐洲中小國家 |
| Super 1000 的 12700 級，只有冠亞軍數字有出處 | 少數站的非冠亞軍 | 現行規章 V6.0 在 robots.txt 禁止的網域，需要手動下載 |
| 資格賽積分的算法是假設（比正賽首輪低一級，每往前一輪再低一級） | 中後段 | 規章沒有細寫 |
| 2020–2021 凍結期解凍後的特殊處理沒做 | 只影響 2021 年的估算 | 不在驗證範圍 |

## 重現方式

```bash
python -m brief.results --db data/brief.db                   # 每站成績（含團體賽）
python -m brief.ranking_estimate --db data/brief.db --from 2024-06-04 --to 2025-08-05   # 歷史排名（團體賽平均分要用）
python -m brief.results --db data/brief.db                   # 用歷史排名重算團體賽
python -m brief.ranking_estimate --db data/brief.db --official-weeks
python -m brief.validate --db data/brief.db
```

程式：`brief/ranking_points.py`（積分規則表）、`brief/results.py`（每站成績）、`brief/ranking_estimate.py`（每週排名）、`brief/validate.py`（驗證指標）。
