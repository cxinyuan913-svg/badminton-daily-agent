# 交接單 003：決賽日自動產生 60 秒口播腳本＋外國選手譯名表

2026-10-01，claude.ai 撰寫。Raymond 已定案（P3 第一步）。

## 目標

每站**決賽日打完**（`brief.watch` 發完該站決賽那天的訊息後），自動產生一份 60 秒口播短影音的**腳本草稿**，推到 Discord 日報頻道給 Raymond 審稿。先只做腳本與字卡，不做配音、不做影片。

參考格式：Bilibili「羽球小月亮」（30–90 秒、本國視角、懸念標題、一天一支）。我們的差異化：**排名反差、交手紀錄、生涯數據**，都由資料庫算出。

## 1. 外國選手譯名表（先做，腳本與日報都會用）

- 新檔 `config/players_zh_foreign.csv`：`bwf_player_id, 英文名, 中文譯名, 國家, 來源, 狀態(candidate/confirmed/rejected), 證據`。
- 範圍：各項目最新官方排名前 50 名的外國選手（約 250 人）＋之後腳本／日報實際出現的外國選手。
- **譯名來源：台灣媒體原文**，沿用暱稱收集的做法（`brief/nickname.py`）：
  - 從已收的中央社、NOWnews 等台灣新聞中，找「中文名（英文名）」或「中文名＋國家＋英文名」並列的寫法，對回 BWF 選手。
  - 必附原文證據（標題或句子＋網址）；同一譯名 ≥ 2 個來源 → `confirmed`，否則 `candidate`。
  - 兩個譯名衝突（例如中央社與 NOWnews 不同）→ 以中央社為準，另一個記在證據欄。
  - **不要用 LLM 或拼音自己造譯名。** 找不到台灣媒體譯名的選手維持英文。
- 中國、香港、新加坡、馬來西亞華裔選手：BWF 名字是拼音，可用新聞找漢字，但一樣要證據（簡繁轉換用台灣慣用字）。
- 週一的暱稱週報加一段「本週新增譯名」，讓 Raymond 確認。
- 日報與腳本：外國選手有 `confirmed` 譯名時寫「坤拉武特（泰國）」，沒有就用英文。
- 範例腳本裡的譯名（坤拉武特、駱建佑、法罕、卡納多／馬汀、王昶／梁偉鏗、白荷娜／李紹希、譚寧／劉聖書、安洗瑩、山口茜、魏雅欣／蔣振邦）是 claude.ai 暫用的，**要用上面的機制核對**，結果列在 status.md。

## 2. 腳本產生

### 觸發與輸出
- 時機：`brief.watch` 發完某站**決賽那天**的訊息後。只做推送層級的賽事（含空檔週升格的 IC／IS）。
- 輸出：
  - 檔案 `data/scripts/YYYY-MM-DD_{tournament_id}.md`（不進版控）
  - Discord 日報頻道另發一則「🎬 影片腳本草稿｜{賽事}」，內容為 3 個標題＋腳本表格（Discord 不支援表格 → 改成每段一行「`0–4s` 口播… ／ 字卡：…`」）
- 模型：`heavy`（`claude-opus-5-5`），每則記入 `llm_call`。估計每支 < US$0.10，status.md 回報實際費用。

### 素材（程式先算好，交給 LLM 的是「事實清單」，不是原始資料）
`brief/storylines.py`：從資料庫產生候選故事，每則有 `kind`、`score`、`facts`（可驗證的數字與名字）：
- `rank_gap`：勝方排名比敗方差很多（例：#43 勝 #3），或一路打掉世界第一
- `comeback`：先輸一局後逆轉；第一局延長（≥ 22 分）加分
- `h2h_dominance`：交手紀錄懸殊（例：8–1）
- `rematch`：與近期大賽決賽同組合、同結果（例：世錦賽決賽重演）
- `home`：中華台北選手的獎牌、最佳成績、與對手的交手紀錄（**每支一定有台灣段落**，沒有台灣選手就寫「台灣選手本站最佳成績」）
- `first_title`：首座同級冠軍（資料庫可查的範圍內）
- 排名：用比賽當週的官方快照（`rank_lookup`），交手紀錄用 `player_match`

### 結構（照範例）
1. 開場 0–4 秒：分數最高的故事，一句話，含一個數字
2. 台灣 約 10 秒
3. 五個項目的冠軍，依故事分數排序，有故事的多講、沒故事的一句帶過
4. 結尾 約 6 秒：互動問句＋下一站預告（下一站名稱從賽程查，查不到就省略預告）
- 全長 240–280 字（約 60 秒）；超過就刪最低分的故事。

### 標題
- 產生 3 個，依範例風格（數字／排名反差＋問句或驚嘆；或「一句話總結最大反差」）。
- 範例中 Raymond 的排序放進提示詞，當作偏好示範。

### 事實檢查（沿用今日重點的做法並加強）
- 腳本與標題中所有**數字**（比分、排名、交手紀錄、名次）都必須出現在事實清單裡；比分整組比對。
- 所有**人名**必須是事實清單裡的名字（中文名、確認過的譯名或英文名）。
- 「爆冷」只能用在 `upset_level` 判定的場次；「逆轉」「首冠」只能用在對應的故事類型。
- 不通過 → 重試一次；再不通過就不發腳本，改發「腳本產生失敗」到告警頻道，附原因。
- 測試：範例資料跑出的事實清單要包含範例腳本用到的所有數字（43、3、19-21 21-13 21-18、26-28、8–1、3–2 等）；捏造一個比分的輸出要被擋下。

## 不做（之後再說）

- 非決賽日的每日短影音。
